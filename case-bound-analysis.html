Case-bound interview analysis

Stage 1: each frozen completed case → one researcher-selected AI → one response containing a separate Participant Information section and the MU → CO → CA → TH analysis. When the researcher-defined cohort is complete, all cases are presented together in one Excel workbook report. The exact requests, exact provider responses, and workbook source records are permanent. Stage 1 cannot complete before every case's complete workbook source is stored. The annotated transcripts are supporting evidence, not substitutes for the one cohort workbook. Researcher viewing is optional. There is no validator, reviewer, repair AI, fallback model, or automatic retry.

Cohort rule: closing a cohort freezes its membership. Any unresolved case blocks it. The three independent whole-corpus operations may run concurrently: CO → HCO, CA → HCA, and TH → HTH. Each request receives only its corresponding preliminary labels. Compact source references preserve lineage outside the model-facing requests; P# is not sent to the model.
