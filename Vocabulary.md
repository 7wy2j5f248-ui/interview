# Interview Quest Shared Vocabulary

This document defines the standard vocabulary used throughout Interview Quest.

Rules:

1. Keys are permanent identifiers and should always remain in English.
2. Values are translated in each language JSON file.
3. Before creating a new key, check whether an existing key can be reused.
4. Keys describe concepts, not pages.
5. Every language JSON file should contain the same keys.
